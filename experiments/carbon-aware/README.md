# 碳感知报价实验

本实验保留 `seed0/` 的原模型、结果和 `snapshot-2026-10-29`，从其中 `full-history/best_joint` 的平台和三个用户继续。根随机种子为0。

## 本轮结果

共同原用户、相同32个测试日场景×4组偏好下，确定性报价结果如下。金额均相对旧合同，单位为元/日；减排为实际全网发电排放变化。

| 方法 | 平台利润增量 | 全网减排（吨/日） | 系统成本节约 |
|---|---:|---:|---:|
| 原PPO | 4250.54 | 0.67165 | 6098.35 |
| 普通PPO等步数续训 | 4398.27 | 0.77840 | 6245.74 |
| 碳感知规则 | 3957.72 | 1.48566 | 6479.56 |
| 碳感知PPO，固定用户 | 4392.25 | 1.24009 | 6461.58 |
| 碳感知PPO，一轮联合 | 4260.38 | 1.29150 | 6164.30 |

预设收益门槛为4178.15元/日。碳规则未达到门槛，不能作为符合收益要求的方案。固定用户碳PPO相比等步数现金PPO，利润均值少6.02元，减排量多0.46169吨（+59.3%），天气配对95%区间为[0.06553, 0.85785]吨/日。

采样执行另行列示：普通续训PPO利润4352.07元、减排0.71147吨；碳PPO利润4249.60元、减排1.21418吨。两个点估计均满足预设门槛。采样没有全面优于确定性执行，模型与执行方式未按测试重新选择。

一轮联合用户更新没有改变本轮实际接收行为，联合训练的额外价值尚未在结果中体现。全网减排与机房分摊碳足迹分别计算：固定用户碳PPO使全网排放相对旧合同减少约0.21%，但机房分摊足迹仍比旧合同增加3.39吨/日。

## 目标与实现

平台目标为：在至少保留参考策略95%的**平均增量现金利润**时，尽量减少全网发电排放。参考利润来自原联合版PPO在全部2048个训练样本上的确定性评估。该目标约束的是期望收益；原市场逐合同的资金约束、用户参与条件和每天的物理碳上限仍照常执行。

平台收到两条真实反馈：实际现金增量（千元）和用户接受后实际产生的全网减排（吨）。拒绝和不报价两条反馈均为零；成交带来的增排保留负号。碳信号不计入账单。三个用户仍各自最大化自己的合同收益。

比较方法：

- 原PPO：冻结的原联合版模型。
- 普通PPO续训：相同起点、相同新增步数、相同KL设置，只优化现金。
- 碳感知规则：根据已报价合同的公开接受记录估计接受概率，最大化“预期减排 + 权重×预期现金”。权重仅在训练集标定。若所有候选均未达到95%收益目标，结果中明确记录未达到和差额。
- 碳感知PPO：独立的现金、碳价值网络；根据完整训练日的利润缺口调整非负约束权重，再优化二者合成的优势。

两个训练分支各新增49,152个平台决策步，使用同一套冻结用户。训练集接线测试发现已训练模型用3e-4继续更新会出现较大的单步KL变化，因此两个分支统一使用5e-5和target_kl=0.02。随后各做一轮联合更新：三个用户分别4,096步，平台8,192步，其他智能体在每一阶段保持冻结。主比较使用共同的原用户；联合用户的结果另行分组，同组内每种方案面对同一套用户。

模型按验证集选择。最终测试使用此前未使用的32个公共日场景（80000–80031），每个场景4组独立偏好。最终测试不参与选择模型或规则权重。训练日志、选择记录、模型和测试表保存在 `seed0/`。

确定性执行与按策略概率采样执行分别评估。采样执行固定同一套原用户，每个案例取4条动作轨迹；使用相同的验证集已选模型，不据测试结果重新选择执行方式。约束对应期望收益，取最大概率动作后的策略需要单独评价。
